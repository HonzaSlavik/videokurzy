# Design context — kurzy.jakdelatprojekty.cz

Sdílený design context pro AI-asistované úpravy UI. Aktualizovat ručně,
když se mění značka nebo cílovka. Zdrojem pravdy pro barvy je
`src/styles/input.css` (`:root` tokeny a `@theme`).

## Use cases

1. **Landing → checkout**: rychle pochopit nabídku, zaplatit kartou (Stripe)
   nebo převodem (FIO + QR), získat magic-link login.
2. **B2B objednávka s fakturou**: IČO, načtení z ARES, zálohový doklad,
   faktura po platbě.
3. **Sledování kurzu**: přehrávač a sledování postupu.
4. **Admin**: granty, správa uživatelů a kurzů.

## Visual language

- **Značka**: zlatá `#A1873C` (`--brand`), jen plochy, ikony a dekor. Jako
  barva textu na světlém pozadí nestačí kontrastem (3,1:1).
- **Akcent**: ztmavená zlatá `#7A6626` (`--accent`) pro odkazy, tlačítka
  a hlavičku s bílým textem (5,6:1). Hover `#5E4E1C` (`--accent-2`).
- **Neutrály teplé**: pozadí `#F7F5EF`, karty `#FFFFFF`, text `#1F1D18`,
  tlumený text `#5D5A52`, patička `#3A3833` se světlým textem.
- **Tailwind**: `indigo-*` je přemapované na zlatou škálu a `gray-*` na teplé
  neutrály (`@theme` v input.css). V šablonách proto `indigo-600` = akcent.
  Nové barvy značky přidávej tam, ne natvrdo do šablon.
- **Stavové barvy** (zelená úspěch, červená chyba, amber varování, modrá
  a fialová pro štítky v adminu) zůstávají oddělené od značky.
- **Fonty**: Space Grotesk (text a nadpisy) + IBM Plex Mono (technické údaje).
- **Kontrast**: každý text min. 4,5:1 (WCAG AA). Ověřit před změnou barev.
- **Žádný dark mode**, žádné dekorativní gradienty.

## Layout principles

- **Asymetrie není priorita** — checkout/dashboard mají centered card layout
  (typický nákupní flow); landing/watch mají širší volnější layout.
- **Plochá hierarchie** — vyhýbat se card-in-card, raději separátory + bílá plocha.
- **Mobile-first** — Tailwind `sm:`/`md:` breakpointy. Touch targets ≥ 44px.

## What to avoid (AI tells)

- Gradient submit buttons (indigo→violet, amber→orange) — neimitovat AI šablonu.
- Nadbytečné `font-mono` mimo skutečně technický obsah (kód, IBAN, VS).
- Glassmorphism, neon-on-dark, AI cyan-on-purple.
- "Hero metric" layouty s velkými čísly.
- Generic `shadow-lg` všude.

## Tech stack constraints

- **Hono JSX SSR** + htmx pro interaktivitu (žádný React/Vue).
- **Tailwind v4** (utility-first, žádný design token system zatím — TODO).
- **Cloudflare Workers** runtime → žádné Node-only API.
- **D1 + Drizzle** ORM, schema versioned přes drizzle migrations.

## Component conventions

- Buttons: `font-semibold` (ne `font-bold`), `rounded-lg`, solidní barvy.
- Inputs: `rounded-lg border-gray-300 focus:ring-2 focus:ring-indigo-500` (indigo = zlatá).
- Cards: jedna úroveň — `bg-white border border-gray-200 rounded-xl`.
- Callout boxes: `bg-{color}-50 border border-{color}-200` (amber=info,
  red=error, green=success).
